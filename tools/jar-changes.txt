# The jar entries that can be different from the reference jars, for tools/compare-jars.ps1.
# The reference is the 7 jars of the tag v0.5.1, the last release (docs/ARCHITECTURE.md, "Check and test").
# Format: <entry wildcard> <reason>. Add a line in the commit that changes the entry.
architectury_inject_* The Architectury transformer puts a random id in this folder name in each build.
mixins.albedo.refmap.json The Mixin annotation processor of the 1.8.9 build writes the mixins in a different sequence in each build.
albedo.mixins.json The build writes the client list from the mixin classes of the node, in ASCII sequence.
fabric.mod.json The Fabric jar asks for Fabric Loader 0.15.0, the first version with MixinExtras, not for the version of the build.
dev/albedo/fabric/AlbedoFabric.class The entrypoint gives the config folder of Fabric Loader to the mod.
dev/albedo/neoforge/AlbedoNeoForge.class The entrypoint gives the config folder of NeoForge to the mod.
dev/albedo/modern/ModernHooks.class bootstrap(File) takes the config folder of the loader, the optional hooks, the cloud option and the flat sky hook count their runs, processSprite takes a SpriteAccess, and the fog keeps its vanilla color when the sky stays vanilla with a shader pack, and skipMouseGrab() tells MouseGrabMixin to skip the grab with the harness.
dev/albedo/modern/ModernPlatform.class configDir() gives the config folder of the loader, and the folder of the game only when the loader gave none, and text() makes a text component for the screens and the message.
assets/albedo/shaders/core/sky_baked_classic.* The GL family draws the baked sky with a program of the mod.
dev/albedo/core/sky/SkyShaderSource*.class The constant BAKED names the program of the baked sky, and two dialects of 26.2 have a reversed depth buffer.
assets/albedo/shaders/core/sky_sharp_classic.vsh The far depth of a reversed depth buffer is a define that only 26.2 sets.
dev/albedo/core/dev/HookCounter.class A new class counts the runs of one optional hook.
dev/albedo/core/dev/Harness.class The harness has the commands hooks, keepframe and framechanged, and runs no command while the loading screen shows.
dev/albedo/modern/mixin/BiomeColorsMixin.class The water tint with no tint is opaque white on 26.x, because 26.x uses its alpha; 1.21.x reads only its red, green and blue and keeps the old value.
dev/albedo/core/dev/Harness$Host.class The host gives the hook counters and tells whether the loading screen shows.
dev/albedo/modern/mixin/SkyMixin.class The flat sky hook goes into each addSkyPass overload, because NeoForge 1.21.11 calls one that vanilla does not have.
dev/albedo/core/ui/ScriptedInput*.class A ui command whose label or slider the screen does not show logs "! no such control".
dev/albedo/legacy/LegacyHooks.class The optional hooks of 1.8.9 count their runs, and the sprite, quad and fog parts with names of one version moved to SpriteUpload and Game, and skipMouseGrab() tells MouseGrabMixin to skip the grab with the harness.
dev/albedo/legacy/LegacyHarnessHost*.class The host gives the hook counters and reads the world, the player, the sound and the world creation through Game.
dev/albedo/legacy/mixin/BlockModelRendererVanillaMixin.class The handlers count their runs, and a quad goes through Game.addQuad.
dev/albedo/legacy/Game.class A new class has the game members whose names are different on 1.8.9 and 1.12.2.
dev/albedo/legacy/GuiSettings.class The font comes from Game.
dev/albedo/legacy/LegacyPlatform*.class The world, the folder, the floor and the message come from Game, and the version name from ForgeVersion.
dev/albedo/legacy/LegacySharpSky*.class The quad draws through Game, and the line numbers moved.
dev/albedo/legacy/LegacySky.class The world, the atlas location and the sphere and mesh draws go through Game.
dev/albedo/legacy/ReloadScreen.class The font and the background draw come from Game.
dev/albedo/legacy/OptiFineRenderPatch.class The OptiFine quad hook calls Game.addQuad.
dev/albedo/legacy/SpriteUpload.class SpriteUpload.process is the sprite hook of 1.8.9.
dev/albedo/legacy/mixin/TextureAtlasSpriteMixin.class The handler calls SpriteUpload.process.
dev/albedo/legacy/mixin/EntityRendererMixin.class The fog of the camera comes from Game.specialFog.
mixins.albedo.json The legacy build writes the client list from the mixin classes of the version, in ASCII sequence.
dev/albedo/legacy/mixin/ForgeBlockInfoMixin.class The handler counts its runs.
dev/albedo/legacy/mixin/ForgeVertexLighterMixin.class The handler counts its runs.
dev/albedo/legacy/mixin/ReloadListenersMixin.class The handler counts its runs.
dev/albedo/legacy/mixin/RenderGlobalMixin.class The handlers count their runs.
dev/albedo/legacy/mixin/SimpleTextureMixin.class The handler counts its runs.
dev/albedo/modern/GlState.class A new class holds the GL state that a raw GL draw reads and puts back, with the pixel buffers unbound for the work of ofAll, because 1.21.5 leaves a pack buffer bound.
dev/albedo/modern/GlProgram*.class A new class compiles and links the GL programs of the mod.
dev/albedo/modern/GlMesh.class A new class holds a vertex array and a buffer of the mod.
dev/albedo/modern/GlSky*.class A new class has the 1.21.1 part of ModernSky and draws the baked sky with a program of the mod; with an Iris shader pack the sky of 1.21.1 stays vanilla (ModernSky.vanillaWithPack); it also has the SkyRenderer entry and the main target binding of 1.21.5, which 1.21.1 does not call.
dev/albedo/modern/GlSharpSky*.class The sharp sky of 1.21.1 uses no vertex or shader class of the game, and its black sphere writes the alpha 0, as 1.21.11 does; skycompare reads its pixels through the GL with no row length or skips.
dev/albedo/modern/GlChromaPass*.class The Chroma pass of 1.21.1 uses GlProgram and GlState.
dev/albedo/modern/PearlSky.class A new class has the 26.3 part of ModernSky.
dev/albedo/modern/PrecompiledSky.class A new class has the 1.21.11 part of ModernSky.
dev/albedo/modern/ModernSky.class The class keeps only the parts that all versions share, vanillaWithPack is the shader pack rule of the sky and the fog, and drawDisc sends the sky disc of 1.21.2 and later to the sky class of the family.
dev/albedo/modern/mixin/SkyLayersMixin.class The handlers call the sky class of the family, on 1.21.1 the other sky parts follow the result of the sky draw, and from 1.21.2 the handlers take no parameters, because the parameters change between the versions.
dev/albedo/modern/mixin/SkyAfterSolidMixin.class The handler calls the sky class of the family and counts its runs.
dev/albedo/modern/SettingsScreen*.class The canvas and its images are classes of their own, the key table is a Java 8 switch, the title comes from ModernPlatform.text, and the start of text input is a method that runs only on 26.3.
dev/albedo/modern/ExtractorCanvas.class A new class has the canvas of 26.x.
dev/albedo/modern/GraphicsCanvas.class A new class has the canvas of the versions before 26.1, and the texture draw of TextureScreen.
dev/albedo/modern/CanvasImages.class A new class has the images of the canvas.
dev/albedo/modern/TextureUploads*.class The sprite upload of each family is a class of its own, and the load step of a stand-alone texture is a method with a variant for 1.21.4 to 1.21.10, which ReloadableTextureUpload has.
dev/albedo/modern/mixin/SkinTextureMixin.class Only the line numbers change on 1.21.1, because the file has a variant for 1.21.4 to 1.21.10.
dev/albedo/modern/DeviceAtlasUpload.class A new class has the sprite upload through the GPU device.
dev/albedo/modern/GlAtlasUpload.class A new class has the sprite upload of 1.21.1.
dev/albedo/modern/SpriteAccess.class A new class gives the pixels and the name of a sprite.
dev/albedo/modern/ChromaAtlases.class The class reads a sprite through SpriteAccess and makes its backend in a method.
dev/albedo/modern/mixin/SpriteLoaderMixin.class The handler gives a SpriteAccess to the hook.
dev/albedo/modern/ModernHarnessHost.class The host is split by topic, gives the hook counters and tells the harness while the loading screen shows.
dev/albedo/modern/Harness*.class New classes have the worlds, options, window, mouse, keyboard, screenshots, frame pixels and skins of the harness host, and the game rules of a new world come from a method with a variant for each version.
dev/albedo/modern/TextureScreen.class The title comes from ModernPlatform.text, the texture id comes from HarnessSkins, and before 26.1 GraphicsCanvas draws the texture, with a blit that takes GraphicsCanvas.TEXTURED from 1.21.2.
dev/albedo/modern/mixin/BlockTintMixin.class Only the line numbers change, because the file has a condition around it.
dev/albedo/modern/mixin/FullbrightMixin.class Only the line numbers change, because the file has a condition around it.
dev/albedo/modern/mixin/ShadowMixin.class Only the line numbers change, because the file has a condition around it; 1.21.2 to 1.21.8 have a selector that takes each method with a name that starts with render.
dev/albedo/modern/mixin/SodiumTintMixin.class The file has a condition around it, and a new handler with require = 0 reads the tint index of Sodium 0.6.13 and 0.7 on 1.21.4 to 1.21.10, whose quad class is in the package frapi.mesh.
dev/albedo/modern/DeviceApi*.class A new class has the calls of the GPU device that changed from 1.21.6 to 26.2, so that 1.21.8 to 26.2 share the sky and Chroma of 1.21.11.
dev/albedo/modern/PrecompiledSharpSky*.class The device calls that changed from 1.21.10 to 26.2 go through DeviceApi.
dev/albedo/modern/PrecompiledChromaPass*.class The pipelines, passes, textures and the timer go through DeviceApi.
dev/albedo/modern/mixin/FogMixin.class From 1.21.6 to 1.21.10 the handler takes no parameters of computeFogColor, which has one more on 1.21.8 and 1.21.10, and gets the camera of the frame; on 1.21.1 and 1.21.11 only the line numbers change.
dev/albedo/modern/mixin/SkinTextureMixin.class Only the line numbers change, because 1.21.4 to 1.21.10 have a branch of their own with ResourceLocation.
dev/albedo/modern/mixin/DryFoliageColorMixin.class The handler counts its runs.
dev/albedo/modern/mixin/SodiumAmbientOcclusionMixin.class The handler counts its runs.
dev/albedo/modern/mixin/AmbientOcclusionMixin.class The common code is compiled against the annotations of Mixin 0.8.5, which write the one "at" of a redirect as a value and not as an array, with the same meaning.
dev/albedo/modern/mixin/SkySunriseMixin.class The sunrise fan redirect of SkyLayersMixin is a mixin of its own, so that a version without the redirect can leave it out.
dev/albedo/modern/mixin/MouseGrabMixin.class A new mixin skips the window calls of the mouse grab and release only when the harness runs, with require = 0.
dev/albedo/legacy/mixin/MouseGrabMixin.class A new mixin skips the LWJGL mouse grab and the cursor move only when the harness runs, with require = 0.
dev/albedo/core/dev/CursorClip.class A new class is the check of the harness command cursorfree.
dev/albedo/modern/KeyCodes.class A new class has the key codes of the screens and the harness, because InputConstants has them only from 1.17.
