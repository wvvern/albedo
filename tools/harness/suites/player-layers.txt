# Player armor off hides the armor and the elytra of players, Player cape off hides their capes. The armor stand (left in the
# front view) and the zombie (right) keep theirs. Run it after the scene:
# python -m tools harness fabric-26.3 --suite player-layers --out build/cape
# The dev player has no cape, so the cape shots show no change; the hooks line shows that the cape layer ran (cape=N).
# 1.8.9 has no elytra, so the lines that name it do not run there.
wait 60
# A zombie despawns in peaceful.
run difficulty easy
modern: run tp @p 0.5 -60 4.5 180 0
legacy: run tp @p 0.5 4 4.5 180 0
modern: run summon armor_stand 2.5 -60 4.5 {Rotation:[180f,0f]}
modern: run summon zombie -1.5 -60 4.5 {NoAI:1b,IsBaby:0b,Rotation:[180f,0f]}
legacy: run summon ArmorStand 2.5 4 4.5 {Rotation:[180f,0f]}
legacy: run summon Zombie -1.5 4 4.5 {NoAI:1,IsBaby:0,Rotation:[180f,0f]}
modern: run item replace entity @p armor.head with minecraft:diamond_helmet
modern: run item replace entity @p armor.chest with minecraft:diamond_chestplate
modern: run item replace entity @e[type=armor_stand] armor.chest with minecraft:diamond_chestplate
modern: run item replace entity @e[type=zombie] armor.head with minecraft:diamond_helmet
modern: run item replace entity @e[type=zombie] armor.chest with minecraft:diamond_chestplate
legacy: run replaceitem entity @p slot.armor.head minecraft:diamond_helmet
legacy: run replaceitem entity @p slot.armor.chest minecraft:diamond_chestplate
legacy: run replaceitem entity @e[type=ArmorStand] slot.armor.chest minecraft:diamond_chestplate
legacy: run replaceitem entity @e[type=Zombie] slot.armor.head minecraft:diamond_helmet
legacy: run replaceitem entity @e[type=Zombie] slot.armor.chest minecraft:diamond_chestplate
